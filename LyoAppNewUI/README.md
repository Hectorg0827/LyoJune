# LyoAppNewUI

This repository contains the new, fully functional iOS UI for Lyo, built with SwiftUI. It is designed to connect to a live FastAPI backend.

## 🚧 Project Status

This project is currently under development. The structure has been scaffolded, and features are being implemented iteratively.

## 🚀 Getting Started

This project is structured as a Swift Package, which allows Xcode to handle project generation automatically.

### 1. Opening the Project
Simply open the `Package.swift` file located in the root of this repository with Xcode 15.4 or later. Xcode will automatically generate the project and workspace files.

### 2. Configuring Schemes
The repository is configured for two main schemes, which you will need to create and share in Xcode for the CI/CD pipeline to work correctly.

*   **`LyoApp` (Debug):** This is the default scheme for development and testing. You can use the one auto-generated by Xcode.
*   **`LyoApp_Production` (Release):** This scheme is used for production builds. To create it:
    1. Go to "Product" -> "Scheme" -> "Manage Schemes...".
    2. Select the `LyoApp` scheme and click the settings icon to "Duplicate" it.
    3. Name the new scheme `LyoApp_Production`.
    4. Click "Edit..." on the new scheme.
    5. In the "Build" tab, set the "Build Configuration" to **Release**.
    6. Ensure the "Shared" checkbox is checked for this new scheme so it's committed to the repository.

### 3. UI Tests Target
The `UITests` folder is included, but Swift Package Manager does not yet support iOS UI Test targets. You will need to add a UI Testing target manually in Xcode and add the placeholder files from the `UITests` directory.

## 🛠️ Configuration

The application requires configuration values to be provided, typically via an `Info.plist` or a `.xcconfig` file. As these were not provided, the application has been built with placeholder values.

**You must provide the following values to run the app successfully:**

| Key | Placeholder Value | Description |
| --- | --- | --- |
| `LYO_BASE_URL` | `https://api.lyo.app` | The base URL for the Lyo REST API (v1). |
| `LYO_WS_URL` | `wss://ws.lyo.app` | The WebSocket URL for real-time communication. |

### OAuth Credentials

The app includes UI and code paths for the following authentication providers. The final SDK calls are gated. To enable them, you must provide the necessary credentials and uncomment the relevant build flags.

-   **Apple Sign In**: Service ID
-   **Google Sign In**: Client ID
-   **Meta (Facebook) Sign In**: App ID

### Staging / Test Users

To validate all application flows, especially those requiring authentication, one or more test accounts for the staging environment are required.
